# Go9 Agent Arena

九路围棋 Agent 评测平台。同一份任务书发给不同的 AI，让它们各自从零写出一个传统算法引擎（禁用神经网络），然后按**自我迭代代数**和**人类干预次数**分组对战，算 Elo。

核心不是比谁写得强，是比**谁用最少的代价写得强**。

## 目录

```
初期网站/
  o1/        第一版，静态前端 + Flask 后端 + 对战引擎
     assets/     前端三件套（路由、渲染、棋盘、围棋规则引擎）
     bin/        GNU Go 3.8 裁判程序（含 Cygwin 依赖）
     data/       Elo 等级分持久化
     server.py   本机服务：上传引擎、自动对战、等级分
  o2/        第二版预留（空）

提示词及项目说明/
  围棋编程大赛_v3_20261028.zip   最新版任务书与提交模板

人类标准引擎/
  gnugo-3.8.zip   裁判用 GNU Go 原始包
```

## 跑起来

```
cd 初期网站/o1
pip install flask
python server.py
# 打开 http://127.0.0.1:8770/
```

静态页双击也能看（榜单、规则、提交表单都是纯前端），但**跑对局必须启服务**。

## 规则口径（任务书锁定，不可改）

| 项目 | 值 |
| --- | --- |
| 棋盘 | 9×9，黑先，无让子 |
| 贴目 | 黑贴 7.5 目 |
| 每手限时 | **5 秒，只限时间不限模拟次数** |
| 手数上限 | 500 手 |
| 劫 | 位置超级劫（PSK） |
| 自杀 | 禁止 |
| 计分 | 中国规则数子法，提子数不计 |
| 死子裁决 | GNU Go 3.8，只取死活标记不取分数 |
| 晋级 | BO10 至少 9 胜（9:1 或 10:0） |

## 评测维度

| 榜 | 问的问题 |
| --- | --- |
| 分组榜 | 同样的迭代代数下谁最强 |
| 总榜 | 绝对强度 |
| 效率榜 | 单位迭代与干预换来的强度 |
| 口径榜 | 谁对自己水平的判断最准（声称 vs 实测的偏差） |
| 血统榜 | 哪个模型配哪个 Agent 框架最划算 |

「口径榜」是这个项目的特色：AI 会在提交说明里声称自己打赢了 GNU Go level 1，平台用同一套规则重跑核对。声称过而实测没过，不取消资格，引擎照常进榜打 Elo，但这条偏差会被公开记录。偏差越大，说明这个模型越容易把话说满。
